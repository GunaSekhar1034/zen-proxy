AI settings — needed for live web search

Gemini (key at aistudio.google.com/app/apikey) and OpenAI (gpt-5.5 etc.) do live web search. OpenAI-compatible works with any base URL — e.g. opencode zen (https://opencode.ai/zen/v1, models like big-pickle, glm-5, kimi-k2), Groq, OpenRouter, or a local server. Everything is stored only in this browser.
OpenCode server talks to a local headless opencode serve at http://localhost:4096 (start it with opencode serve --cors null; put the server password in the API key box, or leave empty if none). Zen itself blocks browser calls, so run the included proxy.js, open the app at http://localhost:8787/, and point OpenAI-compatible at http://localhost:8787/v1.
